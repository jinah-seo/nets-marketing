# NETS 마케팅 운영 키트

넷츠 마케팅 업무(TASK), SNS 게시 계획, 행사 일정, 지표를 한곳에서 관리하는 작업 폴더입니다. 데이터는 `data/` 폴더의 JSON 파일에 있고, 대시보드는 그 파일을 읽고 씁니다. Claude Code는 같은 파일을 고치면서 초안 작성·업무 추가·주간 정리를 돕습니다.

## 윈도우에서 처음 시작하기

### 1. 폴더 두기
압축을 풀어 `nets-marketing` 폴더를 원하는 곳에 둡니다. 예: `C:\Users\<이름>\Documents\nets-marketing`

### 2. Node.js 설치 (대시보드 실행용, 한 번만)
- https://nodejs.org 에서 **LTS** 버전을 받아 설치합니다.
- 설치 확인: 명령 프롬프트(또는 PowerShell)에서 `node -v` → 버전이 나오면 됩니다.

### 3. 대시보드 열기
- 폴더의 **`start.bat`** 을 더블클릭합니다. 검은 창이 열리고 브라우저에 `http://localhost:5173` 이 뜹니다.
- 검은 창을 닫으면 대시보드도 멈춥니다. 쓰는 동안은 열어 두세요.
- `dashboard/index.html`을 직접 더블클릭해서 열면 데이터를 불러오지 못합니다. 꼭 `start.bat`으로 여세요.

### 4. Claude Code 연결
- Claude Code를 설치하고(설치 방법은 https://docs.claude.com 의 Claude Code 안내를 따릅니다) 이 폴더에서 실행합니다.
  - 터미널: 폴더에서 `claude` 실행
  - 또는 Claude 데스크톱 앱의 Code 화면에서 이 폴더를 선택
- 처음 열면 Claude Code가 `CLAUDE.md`를 읽고 업무 기준(회사·일정·SNS 규칙·데이터 규칙)을 압니다.
- 첫 메시지 예: `CLAUDE.md랑 data 폴더 읽고, 이번 주 할 일 정리해줘` 또는 `/weekly-plan`

### 5. 원천 자료 넣기
claude.ai 프로젝트에 있는 회사소개서·제품소개서·구축 사례 파일을 `sources/` 폴더에 넣어 두면, 게시물 초안을 쓸 때 Claude Code가 숫자와 사례를 그 자료에서 가져옵니다. 자세한 건 `sources/README.md`.

### 6. (권장) 변경 이력 남기기
Git이 설치되어 있다면 폴더에서 한 번만:
```
git init
git add .
git commit -m "시작"
```
이후 Claude Code에 "오늘 바뀐 거 커밋해줘"라고 하면 이력이 남고, 실수로 지운 것도 되돌릴 수 있습니다. 대시보드도 저장할 때마다 `data/.backup/`에 직전 파일을 30개까지 남깁니다.

## 자주 쓰는 명령 (Claude Code에서 입력)

| 명령 | 언제 | 하는 일 |
|---|---|---|
| `/weekly-plan` | 월요일 아침 | 늦어진 일, 이번 주 마감, 게시물·제작 마감, 동의 요청 마감 정리 |
| `/draft-post p07` | 게시물 제작 | LinkedIn·Facebook 초안을 `drafts/p07.md`에 작성 |
| `/add-task 내용` | 수시 | 자연어로 업무 추가 (이번 주 부하도 같이 확인) |
| `/friday-log 120 85` | 금요일 | 팔로워 기록, 게시·업무 상태 점검, 주간 요약 |
| `/shift-event seminar 2026-11-26` | 행사 날짜 변경 시 | 관련 마일스톤·게시물 날짜 일괄 이동 |
| `/monthly-report 2026-10` | 월말 | 대표 보고용 월간 보고 초안 |

명령 없이 그냥 말해도 됩니다. 예: "p05 공개 동의 받았어. 메모에 남기고 고객사명 실명으로 초안 다시 써줘"

## 폴더 구조

```
CLAUDE.md          Claude Code 작업 기준 (회사·일정·규칙) ← 가장 중요
README.md          이 파일
start.bat          대시보드 실행
server.js          로컬 서버 (외부 패키지 없음)
dashboard/         대시보드 화면
data/              config · posts · tasks · metrics (JSON)
docs/              콘텐츠 전략 v1.1, 글쓰기 가이드, Q4 계획, 체크리스트, 로드맵, 결정 기록
drafts/            게시물 초안
reports/           주간·월간 보고
sources/           원천 자료 (직접 넣기)
.claude/commands/  위 명령들의 정의
```

## 대시보드 화면

노션처럼 왼쪽 사이드바에서 페이지를 고르고, 표·달력·보드의 항목을 누르면 **오른쪽 상세 패널**에서 모든 필드를 고치거나 지울 수 있습니다. 고친 내용은 바로 저장됩니다.

- **이번 주**: KPI, Q4 타임라인, 2주 안에 할 일, 늦어진 일 (누르면 상세가 열림)
- **업무** (기준 데이터, 할 일 관리는 여기 한 곳에서): 처음 열면 전체 업무(완료 포함)가 보입니다. 사이드바 「업무」 아래 **영역 탭**(행사·SNS·…, 남은 일 수·늦은 일 배지)을 누르면 그 영역만 모아 봅니다 (주소 `#tasks/행사`). 위에서부터
  - 필터(영역·종류·상태·담당·검색)와 「새로 만들기」(업무·확인·SNS 게시물·마일스톤). 필터는 달력과 표에 함께 적용 (상태는 표에만)
  - 월간 달력: 업무(마감일, 영역별 색)와 SNS 게시일·✎ 제작 마감. 날짜 칸의 ＋로 추가, 카드를 끌어 날짜 이동, 몰린 날은 「＋N개 더」. 「달력 접기」로 숨길 수 있음 (다음에 열어도 유지)
  - 업무 목록: 표(영역별 묶음, 하위 마일스톤은 상위 업무 아래 들여쓰기·트리 선, ⋮⋮ 손잡이로 순서·영역 이동) / 보드(상태별, 끌어서 상태 변경)
  - 영역 머리 오른쪽: ＋ 업무 추가 · 이름 수정 · 삭제(업무가 있으면 옮길 영역 선택). 표 맨 아래 「＋ 새 영역」
  - 업무 행에 마우스를 올리거나 누르면 오른쪽에: ＋ 하위(마일스톤 추가) · 편집 · 삭제
  - 체크박스로 완료해도 바로 사라지지 않고 줄이 그어진 채 남습니다 (필터를 바꾸거나 페이지를 옮기면 정리)
  - SNS 게시 운영: 게시물 목록·필러별 진행·톤 가이드
  - 여기서 고친 내용이 이번 주·보고서에 그대로 반영됩니다
- **보고서**: 영역(전체 또는 하나)·기간(이번 주·지난 주·이번 달·지난 달·Q4 전체·직접 선택)·묶음(영역·담당·종류·우선순위·행사)을 골라. 「발행 ▾」으로 그 조건 그대로 Excel(요약+보고 문구+업무 목록) 또는 PDF(전체 / 요약+보고 문구만)를 바로 냅니다. 완료한 일, 마감 이행률(오늘까지 마감 기준), 늦어진 일, SNS 게시, 구분별 표(펼치면 업무 목록), 주별 추이(2주 이상), 활동 내역, 다음 기간 예정을 봅니다. 「보고 문구 복사」로 보고 초안을 붙여 넣을 수 있습니다
- **지표**: 주간 기록 표에서 추가·수정·삭제, 팔로워 추이
- **예산**: 연도 탭(2026 행사 예산 · 2027 예산안 · 「＋ 연도」로 추가, 작년 구분·항목 복사 가능). 계획·실집행·집행률, 승인액, 예비비 잔액. 표는 구분(큰 항목, 굵은 줄) 아래에 하위 항목. 구분 줄에서 이름을 눌러 바꾸고 ↑↓로 순서, ×로 삭제 (하위 항목을 「구분 없음」으로 남기거나 함께 지우기 선택), 표 맨 아래 「＋ 새 구분」으로 추가. 「새로 만들기」 또는 행을 눌러 상세에서 항목의 연도·구분·금액·업체·지급일·연결 업무·메모 수정과 삭제. 표 칸에서 바로 고쳐도 됨. 연도마다 승인액·예비비 비율 설정, 연도별 요약 비교
- **회의**: 정기 회의(주간회의 매주 화 09:00, 영업 회의 격주 목 09:00)가 12/31까지 미리 들어 있습니다. 「새 회의 ▾」로 마케팅 회의·기타 회의를 추가하고, 회의를 누르면 오른쪽에서 안건·주요 내용·결정 사항·할 일을 적습니다. 할 일 옆 「업무로 ▾」를 누르면 영역을 골라 업무로 등록됩니다. 맨 아래 「정기 회의」에서 요일·시간·주기를 바꿀 수 있습니다
- **⤓ 내보내기** (각 페이지 오른쪽 위, 별도 페이지 없음): 창이 열리면 그 페이지 자료와 지금 필터가 골라져 있습니다. 다른 자료(업무·SNS 게시물·지표·예산·보고서 요약)도 더 고를 수 있고, 자료마다 필터와 열을 골라 미리 본 뒤 저장
  - Excel(.xlsx): 자료마다 시트 하나, 머리글 고정·필터, 금액·날짜·비율 서식, 소계·합계 굵게, 하위 항목 └ 들여쓰기. 보고서 요약을 고르면 「보고 문구」 시트 추가
  - CSV: 자료마다 파일 하나 (엑셀에서 한글 안 깨짐)
  - PDF: 인쇄 창이 열리면 대상을 「PDF로 저장」으로. 가로/세로, 제목 지정
  - 고른 설정은 브라우저에 기억됩니다. Esc로 닫기
- **🖨 이 화면 PDF** (각 페이지 오른쪽 위): 지금 보이는 화면(타임라인·차트 포함)을 사이드바 없이 인쇄 → 「PDF로 저장」
- **설정**: 행사 일정 추가·수정·삭제, 타임라인 범위·UTM·규칙, 선택지 목록(필러·상태·우선순위·영역·담당) 추가·이름 바꾸기·삭제. 이름을 바꾸면 쓰고 있는 항목도 함께 바뀝니다. 🔒 표시 값은 계산에 쓰여 고정입니다

주소 끝에 `#budget`, `#tasks`, `#meetings`, `#report`처럼 (예전 `#calendar`·`#sns`는 업무 페이지로) 붙이면 그 페이지가 바로 열립니다 (즐겨찾기용). 상세 패널은 Esc 또는 패널 밖을 눌러 닫습니다.

확장 계획은 `docs/05-dashboard-roadmap.md`에 있습니다.

## 문제가 생기면

- **start.bat을 눌렀는데 창이 바로 닫힘**: Node.js가 설치되지 않았거나 경로가 잡히지 않은 경우입니다. 설치 후 PC를 다시 시작해 보세요.
- **"포트가 사용 중" 오류**: 이미 대시보드가 실행 중입니다. 브라우저에서 `http://localhost:5173`을 여세요.
- **화면에 "데이터를 불러오지 못했습니다"**: `start.bat`으로 연 주소(`localhost:5173`)인지 확인하세요.
- **"대시보드 밖에서 바뀌어 다시 불러왔습니다" 안내**: 대시보드가 켜진 동안 Claude Code 등이 같은 파일을 고친 경우입니다. 덮어쓰지 않으려고 최신 파일을 다시 읽은 것이니, 방금 바꾼 칸만 한 번 더 입력하세요.
- **JSON을 고쳤더니 화면이 비었음**: 파일 문법 오류일 가능성이 큽니다. Claude Code에 "data 폴더 JSON 문법 확인해줘"라고 하거나 `data/.backup/`의 직전 파일로 되돌리세요.
