다음 내용을 업무로 추가해줘: $ARGUMENTS

1. `data/config.json`의 areas·owners·taskStatuses와 `data/tasks.json`을 읽는다.
2. 내용에서 제목, 마감일, 담당, 영역, 우선순위, 상위 업무(세미나면 EV-1, 전시면 EV-2 등)를 추론한다. 추론이 애매한 값만 한 번에 모아서 물어본다.
3. ID 규칙(CLAUDE.md)에 따라 새 ID를 만든다. 행사 하위 일정이면 kind=`마일스톤`, 결정·확인이면 kind=`확인`.
4. 추가하기 전에 같은 주에 마감인 P0·P1 업무 수를 보여 주고, 이번 주가 이미 꽉 찼으면 미룰 후보를 하나 제안한다 (Q4 원칙: 새 업무는 기존 업무 하나를 빼는 조건).
5. 요청한 업무가 `docs/03-q4-plan.md`의 B(2027 이월)·C(보류) 목록에 있으면 먼저 그 사실을 알린다.
6. `data/tasks.json`에 항목을 추가하고, 추가한 항목을 보여 준다. 다른 항목은 건드리지 않는다.
