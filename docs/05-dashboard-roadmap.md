# 대시보드 확장 로드맵

지금 대시보드는 이번 주·업무(+영역 탭)·보고서·지표·예산·설정 여섯 페이지다 (v0.9, 노션형. 캘린더는 업무 페이지에 합침, 내보내기는 각 페이지의 창). 업무(`tasks.json`)가 기준 데이터이고 나머지 페이지는 그것을 보여 준다. 아래 순서로 키운다. 각 단계는 Claude Code에 "로드맵 2단계 진행해줘"처럼 요청하면 된다. 단계마다 데이터 파일을 먼저 정하고, 화면은 그 다음에 붙인다.
