# 행사 현장 콘텐츠 캡처 체크리스트

행사 당일에 모은 소스가 12월~1월 콘텐츠의 원료다. 운영에 바쁜 Megan 대신 사내 1명을 '촬영 담당'으로 지정하고(11/17까지) 이 목록을 전달한다. 사진은 행사 당일 공유 폴더에 모두 올린다.

- [ ] 대표 인사말, 연사별 발표 사진 각 3장 (슬라이드가 보이게)

- [ ] 연사 인터뷰 30초 영상 2개: "오늘 가장 전하고 싶었던 한 가지"
- [ ] Q&A에서 나온 질문 메모 (게시물 소재)

→ 사용처: p11 현장(당일 또는 11/25 오전), p12 리캡(11/26), 12월 결산(p20)
